# Setup before the workshop

1. Install Visual Studio Code.
2. Install a current supported Python interpreter.
3. In VS Code, install the Microsoft Python extension.
4. Create or sign in to a personal GitHub account.
5. In VS Code, enable AI features / GitHub Copilot and activate Copilot Free if prompted.
6. Open this entire folder using File > Open Folder.
7. Put `print("Hello")` temporarily in `main.py` and click **Run Python File in Terminal**. Confirm the terminal prints `Hello`, then restore the starting file.
8. Open Copilot Chat and ask it to read `PROJECT_BRIEF.md` without changing any files.

GitHub Education verification is optional for this workshop. Verified students can activate Copilot Student, but the free workshop path must work with Copilot Free.
